# 달빛보살 (PWA)

정통 사주 풀이를 중심으로 궁합, 신년운세, 별자리, 이름 풀이, 마음 테스트, 위로 카드를 제공하는 설치형 웹앱입니다.
빌드 과정 없이 순수 HTML/CSS/JS(ES 모듈)로 동작합니다.

## 기능
- **사주 풀이**: 원국(십성·지장간·12운성), 오행 분포, 신강·신약과 용신, 신살, 성격, 대운, 세운(올해·내년), 월별 흐름, 행운 포인트
- **궁합**: 상대 정보를 직접 입력하거나, 내 정보를 담은 초대 링크를 보내 상대가 열면 바로 결과 표시
- **별자리**: 태양궁·달궁·상승궁 (열대 황도대, 서울 기준)
- **이름 풀이**: 한글 획수 수리(원형이정 4격), 발음오행
- **오늘의 운세**: 일진과 내 일간의 관계
- **PDF 저장**: 사주 풀이 전체와 마음 리포트를 PDF 파일로 저장 (외부 라이브러리 없이 직접 생성)
- **마음 쉼터**: 1분 숨 고르기, 마음 테스트, 오늘의 위로 카드, 마음 리포트
- **달토끼 보리**: 화면마다 안내해 주는 픽셀 캐릭터
- **풀이의 근거**: 인용한 고전과 심리학 연구, 계산 방법, 참고 문헌
- **결과 카드 이미지** 저장·공유, 양력·음력(윤달) 입력

## 로컬에서 실행
```sh
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```
(`file://`로 직접 열면 모듈과 서비스 워커가 동작하지 않습니다.)

## 구조
| 파일 | 역할 |
|---|---|
| `index.html`, `styles.css` | 앱 셸과 스타일 |
| `js/app.js` | 화면 라우팅과 렌더링, 저장(localStorage) |
| `js/saju.js` | 사주 계산 엔진 (절기·진태양시, 십성, 12운성, 신살, 용신, 대운, 궁합) |
| `js/astro.js` | 태양·달·상승궁 계산 |
| `js/name.js` | 한글 성명학 계산 |
| `js/lunar.js`, `js/vendor/` | 음력 변환 (korean-lunar-calendar, MIT) |
| `js/data-*.js` | 풀이 문구 (`data-notes.js`: 고전 인용, 심리학 노트, 참고 문헌) |
| `js/art.js`, `js/mascot.js` | SVG 일러스트, 픽셀 캐릭터 |
| `js/doc.js`, `js/pdf.js` | PDF 문서 구성과 생성 |
| `fonts/` | Noto Serif KR 서브셋 (SIL OFL, `OFL.txt` 참고) |
| `sw.js` | 오프라인 캐시 (파일을 고치면 `VERSION`을 올리세요) |

## 계산 기준과 한계
- 음력 입력은 1920~2050년 범위에서 양력으로 변환해 계산합니다.
- 일주는 23시(자시)부터 다음 날로 넘깁니다.
- 신강·신약과 용신은 가중치 기반의 간략 판단(억부·조후)이며 학파에 따라 다를 수 있습니다.
- 이름 풀이는 한글 획수 기준입니다(한자 획수 미지원).
- 1950년대 서머타임, 해외 출생지는 반영하지 않습니다.
